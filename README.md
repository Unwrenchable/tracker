# Randy's Field Tech Console

A local-first field operations dashboard.

## Features
- Persistent case board (add / complete / delete) stored in browser localStorage
- Live geolocation + OpenStreetMap view of your current position
- Signal monitor with rotating status
- Command buttons that append timestamped entries to a persistent log
- Fully client-side — no backend required

## Live site
After the GitHub Actions workflow runs, the site is available at:

https://unwrenchable.github.io/tracker/

## Local use
Just open `index.html` in a browser. Data stays on the device.
